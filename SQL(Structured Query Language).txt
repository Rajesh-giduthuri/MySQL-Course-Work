SQL(Structured Query Language)
==========================================================
Structured Query Language developed by "Donald Chamberlin and Raymod boyee in 1970's to handle with relational databases.
SQL is a standard language used to communicate with relational databases to store, retrieve, insert, update, and delete data.
--> Here every command starts with verb and every command ends with ;
--> It is case insensitive language

Sub-languages of SQL : SQL is divided into several sub-lang each one can perform distinct actions.
-------------------------------------------------
1. DDL(Data Definition Language) : Used to define or modify database structures.
- CREATE – Creates database or table.
- ALTER – Modifies table structure.
- DROP – Deletes database or table.
- TRUNCATE – Removes all rows from a table.

2. DML(Data Manipulation Language) : Used to modify data inside tables.
- INSERT – Adds records.
- UPDATE – Modifies records.
- DELETE – Deletes records.

3. DQL(Data Query Language) : Used to retrieve data.
- SELECT – Fetches records.

4. DCL(Data Control Language) : Used to control database permissions.
- GRANT – Gives permissions.
- REVOKE – Removes permissions.

5. TCL(Transaction Control Language) : Used to manage database transactions.
- COMMIT – Saves transaction changes.
- ROLLBACK – Reverses uncommitted changes.
- SAVEPOINT – Creates a point to roll back to.

Data Types in SQL
====================================================
specify what kind of values a column can store in a database table.

1. Numeric Data Types : Used to store numbers
--Exact numeric data types [INT(4 bytes), TINYINT(1 byte), SMALLINT(2 bytes), BIGINT(8 bytes), BIT(1 bit), Decimal(precision, scale)]
--Approximate data types [Float(4 or 8 bytes), Real]

2. String Data Types : Used to store text and characters
[CHAR, VARCHAR, TEXT]

3. Date and Time Data Types : Used to store dates and time values
[DATE, TIME, YEAR, DATETIME, TIMESTAMP]

4. ENUM (Enumeration) is a string data type in MySQL that allows a column to store only one value from a predefined list of values.
CREATE TABLE employee (
    emp_id INT,
    emp_name VARCHAR(50),
    gender ENUM('Male', 'Female', 'Other')
);
