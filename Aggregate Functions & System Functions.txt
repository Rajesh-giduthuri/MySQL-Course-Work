AGGREGATE FUNCTIONS():
================================
Aggregate functions performs calculations on multiple rows and returns single value

COUNT(): returns the number of rows or non-null values in a column
Syntax:
select count(column_name);
------------------------------------

COUNT(*): It is used to count the total number of rows in table including rows containing null values
Syntax:
select count(*) from table_name;
------------------------------------

SUM(): returns total sum of values in a column, null values are ignored
Syntax:
select sum(column_name);
------------------------------------

AVG(): returns avg value of numeric column, null values are ignored
Syntax:
select avg(column_name);
------------------------------------

MAX(): returns the highest value from column
Syntax:
select max(column_name);
------------------------------------

MIN(): returns the lowest value from column
Syntax:
select min(column_name);
------------------------------------


SYSTEM FUNCTIONS():
===================================
Returns information about MySQL server, current database, user and connection

VERSION(): returns the version of MySQL currently being used
Query:
select version();
------------------------------------

DATABASE(): returns name of current selected database. returns null if no database is seleted
Query:
select database();
------------------------------------

USER(): returns MySQL account name and host name supplied by the client when connecting to the server
Query:
select user();
------------------------------------

CONNECTION_ID(): returns the unique connection id assigned to the current MySQL connection
Query:
select connection_id();
------------------------------------

LAST_INSERT_ID(): returns the auto_increment value generated by the most recent successful insert statement in current connection
Query:
select last_insert_id();
------------------------------------


GROUP BY:
=================================================
Group By is used to group rows that contain the same values in one or more columns

Rules:
-->Group By is used with aggregate functions like count(), sum(), avg(), min(), max()
-->Group By is written after WHERE clause
-->We can use multiple columns in Group By 
-->Every non aggregated column in select must be included in Group By
-->Having condition is used to filter Grouping 

Syntax:
select column_name, AGGREGATE_FUNCTION(column_name)
from Table_name
GROUP BY column_name;
------------------------------------

HAVING :
================================================
Having is used to filter groups after applying the group by clause 

Syntax:
select column_name, AGGREGATE_FUNCTION(column_name)
from Table_name
GROUP BY column_name
HAVING condition;
------------------------------------
